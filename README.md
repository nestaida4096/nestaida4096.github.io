# Oyama142859 — Personal Website

A responsive, single-page Japanese portfolio built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` — portfolio homepage
- `contact.html` — social/contact links
- `styles.css` — layout, responsive styles, and motion
- `script.js` — scroll reveals and landscape parallax
- `assets/` — brand icon and favicon

## Development

Open `index.html` in a browser. No build step or package manager is required.

## Deployment

GitHub Actions deploys the repository root to GitHub Pages when changes are pushed to `main`.

The site respects `prefers-reduced-motion` and provides a reduced-animation experience when requested by the operating system.
